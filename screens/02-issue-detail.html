description Issue Description

Opened 2 days ago by @devuser

When parsing deeply nested template tags containing inline filters, the parser raises an unexpected `TemplateSyntaxError`. This appears to happen specifically when the depth exceeds 3 levels of nesting inside a block tag.

Expected Behavior

Parser should correctly build the AST and evaluate all filters sequentially regardless of nesting depth within reasonable limits (e.g., standard Python recursion limits).

Observed Behavior

Fails at 4th level with `TemplateSyntaxError: Could not parse the remainder`. It seems to drop context of the parent token stream.

Example Trigger

{% block content %}
    {% if user.is_authenticated %}
        {% for item in items|filter_active %}
            {{ item.name|upper|default:"UNKNOWN"|truncatechars:20 }}
        {% endfor %}
    {% endif %}
{% endblock %}
